---

## Why media is currently stored in Drive

The hardware prototype is still changing.

Keeping the original photos and videos in Google Drive makes it easier to:

- upload new build progress quickly
- keep full-resolution originals
- avoid filling the GitHub repository with large temporary files
- replace outdated wiring photos as the prototype changes
- organize videos before publishing final demonstrations

Selected final photos and smaller demo videos may later be added directly to the GitHub repository.
